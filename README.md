  1. Scénario de jeu (point par point)

Le héros (Lior) vit dans un village.
Un mal ancien (Nocthra) se réveille.
Le sage donne une épée et une mission : retrouver 4 cristaux.
Objectif principal
Trouver les 4 Cristaux d’Aube.
Chaque cristal est caché dans un donjon.
Une fois les 4 réunis, accéder au boss final.

2. Quêtes principales
Quitter le village
Parler au sage
Obtenir l’épée et la carte
Forêt Murmurante
Trouver le chemin caché
Aider un esprit de la forêt
Obtenir le 1er cristal
Ruines anciennes
Résoudre des puzzles (leviers, portes)
Éviter des pièges
Obtenir le 2e cristal
Caverne des ombres
Zones sombres (torche nécessaire)
Combattre des monstres
Obtenir le 3e cristal
Montagne céleste
Escalade + ennemis forts
Dernier donjon
Obtenir le 4e cristal
Combat final
Accès au sanctuaire
Affronter Nocthra

3. Donjons (simples)

Donjon 1 : Forêt
Thème : nature
Mécanique : pousser des blocs, suivre des sons
Boss : esprit corrompu
Donjon 2 : Ruines
Thème : ancien temple
Mécanique : interrupteurs, portes
Boss : golem de pierre
Donjon 3 : Caverne
Thème : obscurité
Mécanique : lumière/torche
Boss : créature des ombres
Donjon 4 : Montagne
Thème : air et hauteur
Mécanique : plateformes mobiles
Boss : gardien ailé

4. Personnages

Lior : héros, jeune aventurier
Le Sage : donne la mission
Esprit de la forêt : aide dans le 1er donjon
Marchand : vend objets et potions

5. Objets

Épée : arme principale, devient plus forte
Bouclier : bloque les attaques
Torche : éclaire les zones sombres
Clé : ouvre certaines portes
Cristaux : objets de quête

6. Boss

Esprit corrompu : rapide, attaque en cercle
Golem : lent mais puissant
Ombre : disparaît et attaque par surprise
Gardien ailé : attaque depuis les airs
Nocthra : boss final, plusieurs phases
