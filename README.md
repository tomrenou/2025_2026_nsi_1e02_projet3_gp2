# 🎮 Lior’s Adventures

> Un jeu d’aventure 2D développé en Python avec Pygame.
> Explorez différents niveaux, combattez des ennemis et incarnez plusieurs versions de **Lior** aux pouvoirs uniques.

---

## 📖 Présentation

**Lior’s Adventures** est un projet de NSI réalisé en groupe.
Le joueur contrôle  **Lior** , un aventurier capable de prendre plusieurs formes :

* ❄️ Lior de glace
* 🔥 Lior de feu
* 🌑 Lior ténébreux
* 💙 Lior classique

Le but du jeu est de :

* explorer la carte,
* récupérer des pièces,
* combattre des ennemis,
* survivre à des monstres de plus en plus puissants.

# 🚀 Installation

## 1. Cloner le projet

```bash
git clone https://github.com/VOTRE-REPO/liors-adventures.git
```

## 2. Installer pygame

```bash
pip install pygame
```

## 3. Lancer le jeu

```bash
python main.py
```
